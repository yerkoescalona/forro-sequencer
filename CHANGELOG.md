# Changelog

All notable changes to this project will be documented in this file. See [standard-version](https://github.com/conventional-changelog/standard-version) for commit guidelines.

## [0.1.0] - 2026-09-04

### Features

- Forró sequencer with zabumba, pandeiro, and triângulo
- Baião, xote, forró, xaxado, coco, and rastapé presets
- Ensemble mode with per-instrument volume control
- Lookahead audio scheduler
- JSON export / import for sequences
- Dark / light theme toggle
- PT / EN language support
- Tutorial and about pages
